PRESENTATION DU PROJET

le projet consiste à établir des tickets de restauration composés du code du plat, du type de plat, du prix unitaire, de la quantité, du nom du client, du montant final, du montant versé.
Pour la création du code, nous avons utilisé :
la variables (let) pour declarer les données de commandes; 
les conditions (if/else; switch) permettent d'appliquer les regles logiques;
la conversion (Number) sert a transformer les nombres en chaînes de caractères;
la boucles(for) pour permettre plusieurs commandes de plats;
la fonction (function calculerTotal(prixUnitaire, quantite) sert a calculer le montant total.

Pour exécuter le programme, on fait : node cantine.js
